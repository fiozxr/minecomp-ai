# minecomp-ai — AI Minecraft Bedrock Agent

A terminal-driven AI agent that joins a Minecraft: Bedrock LAN world and
executes tasks given via chat, using any OpenAI-compatible API.

## Quick Start

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Configure (first run guides you):
   ```bash
   python -m minecomp
   ```

3. On your Minecraft: Bedrock server, run the WebSocket gateway:
   ```bash
   python -m minecomp.gateway --host 0.0.0.0 --port 8080
   ```

4. In your Minecraft: Bedrock world (with the mcbe-ws-sdk addon installed
   and cheats enabled), run `/wsserver <server-ip>:8080`.

5. Back in the terminal, choose a world from the LAN list and the agent
   joins, ready to receive tasks via chat.

## Quick Start (copy-paste ready)

### 1. Install dependencies
```bash
curl -sSL https://github.com/fiozxr/minecomp-ai/raw/main/setup.sh | bash
```

That's it. The installer will:
- Check Python and install dependencies
- Create ~/.minecomp-ai/config.yaml from the example
- Guide you through first-run setup

### 2. Configure your API key
```bash
nano ~/.minecomp-ai/config.yaml
```
Set your `api_key` (OpenRouter, NVIDIA, or any OpenAI-compatible endpoint).

### 3. Set up the Minecraft server side
On your Bedrock server:
1. Install the **mcbe-ws-sdk** addon in the world
2. Start the WebSocket gateway:
   ```bash
   python -m minecomp.gateway --host 0.0.0.0 --port 8080
   ```
3. In the Minecraft world (cheats ON), run:
   ```
   /wsserver <server-ip>:8080
   ```

### 4. Run the agent
```bash
python -m minecomp
```

### 5. Chat with your agent
Players in your LAN world type messages. The AI agent reads them
and responds or executes commands (teleport, give items, change weather, etc.).

## Architecture

```
                        +-----------------------+
                        |  Minecraft: Bedrock   |
                        |  World (cheats ON)    |
                        +----------+------------+
                                   |  /wsserver <host>:8080
                        +----------v------------+
                        |  WebSocket Gateway    |
                        |  (minecomp.gateway)   |
                        +----------+------------+
                                   |
                        +----------v------------+
                        |  minecomp-ai Agent    |
                        |  (terminal UI)        |
                        +-----------------------+
                                   |
                        +----------v------------+
                        |  OpenAI-compatible API  |
                        |  (OpenRouter, NVIDIA) |
                        +-----------------------+
```

## Behavior

- The agent broadcasts a LAN discovery packet; any minecomp-ai-backed
  Bedrock server responds with world info.
- The terminal UI lists discovered worlds; the user picks one.
- The agent connects to the WebSocket gateway on that server.
- Players chat in-game → the message is forwarded to the LLM.
- The LLM decides whether to reply in chat or execute a /command.
- Responses are broadcast to players via /say.

## Configuration

Environment variables and a YAML config file:

| Variable            | Default                          |
| ------------------- | -------------------------------- |
| `MINECOMP_API_KEY` | (required)                       |
| `MINECOMP_BASE_URL`| `https://openrouter.ai/api/v1`   |

Config file: `~/.minecomp-ai/config.yaml`

Example:
```yaml
api_key: "sk-..."
model: "google/gemini-2.0-flash"
base_url: "https://openrouter.ai/api/v1"
gateway_host: "127.0.0.1"
gateway_port: 8080
```

## CLI Options

```
python -m minecomp --api-key KEY --model google/gemini-2.0-flash
       --base-url https://openrouter.ai/api/v1
       --config path/to/config.yaml
```

## Supported Actions

The LLM can send these slash commands to the game:
- `/say <text>` — broadcast a message
- `/tp @p <x> <y> <z>` — teleport
- `/give @p <item> <count>` — give items
- `/time set <day|night|0|1|2|3>` — change time
- `/weather clear|rain|thunder` — change weather
- `/xp <amount>` — give experience


## Requirements

- Python 3.11+
- Minecraft: Bedrock Edition (on a server with cheats enabled)
- A WebSocket gateway on the server (mcbe-ws-sdk based)
- The mcbe-ws-sdk addon installed in the game
- An OpenAI-compatible API key (OpenRouter, NVIDIA, etc.)
